# Phase A — Canonical skeleton

## Scope

This phase establishes the independent repository, backend architecture, database baseline,
structural API, game registry, frontend navigation, design-system primitives and test suites.

## Deliberately excluded

- source-project code and database migration;
- historical data;
- game algorithms and heuristics;
- verified game and prize rules;
- Phase B TRIS integration.

## Status policy

Eight games are `planned`; Lotería Nacional is `awaiting_rules`; none is `available`.
