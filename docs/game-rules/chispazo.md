# Chispazo rules

Rule version `chispazo-2012-03-07`, retrieved 2026-09-06. Official sources: https://www.loterianacional.gob.mx/Chispazo/Chispazo, https://www.loterianacional.gob.mx/Documentos/Legal/ReglamentoJuegos/Reglamento-Chispazo.pdf and https://www.loterianacional.gob.mx/Documentos/Historicos/Chispazo.csv.

The official structure is 5–7 distinct selections from 1–28; a draw has five natural numbers and no additional. Multiple selections expand to every five-number subset. Draws occur daily at 15:00 and 21:00. The CSV has no session field, so the domain preserves draw number ordering and does not infer a session label.

Raw SHA-256: `4d9e15816a9614e2d96fd0d41885a08a4ea1256660e22c6a6066e47fad2f1a06`; parser `combination-csv-1`. Cost rule `chispazo-cost-2026-09-06` is MXN 10.00 per simple combination. Categories are 5/4/3/2 hits; only two hits has the currently verified fixed MXN 10.00 amount. Variable prizes remain null. LT/CA/PC are `not_implemented`; heuristics are not probabilities and ROI is unavailable.
