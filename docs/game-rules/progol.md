# Progol y Progol Revancha

Fuentes primarias: [página oficial](https://www.loterianacional.gob.mx/Progol/Progol), [múltiples oficiales](https://loterianacional.gob.mx/Progol/Coperacha) y [reglamento](https://www.loterianacional.gob.mx/Documentos/Legal/ReglamentoJuegos/Reglamneto-Progol.pdf). Versión: `progol-mx-official-2026-09-06`.

Progol tiene 14 partidos; cada posición se selecciona como Local (`L`), Empate (`E`) o Visita (`V`). El resultado oficial es el de tiempo reglamentario, sin extra ni penales. Tiene cinco niveles; las reglas oficiales determinan corrimientos si faltan ganadores. El precio sencillo vigente es MXN 15.

Revancha es una modalidad complementaria de Progol, requiere participar en Progol y tiene siete partidos. Su sencillo cuesta MXN 5. Su categoría única se reparte al mayor nivel de acierto resuelto oficialmente; los hits de un ticket no bastan para determinar premio.

Múltiples Progol: hasta 8 dobles y 5 triples, con combinación máxima de 2 dobles y 4 triples. Revancha permite hasta 3 dobles y 2 triples. El número de líneas es el producto de opciones por partido y el coste es líneas × precio unitario.

Resultados especiales se preservan con estado y `official_pool_outcome`; los resultados deportivos no se sobrescriben. No se infieren montos de premio.
